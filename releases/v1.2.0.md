# codexQuotadisplay 1.2.0

Windows 11 x64 桌面额度挂件。球内水量表示 5 小时剩余额度，外环表示 7 天剩余额度。

## 本次更新

- 悬停球面查看两组额度各自的本地重置日期、时刻及剩余时长。
- 水色固定为清澈浅蓝，不受外观主题影响。
- 水下加入会摆尾、游动和转身的红白鲤鱼，随水位调整大小和活动范围。
- 保留置顶开关、四边吸附、悬停展开、鼠标缩放、多材质和多种动效。

## 下载与使用

- `CodexUsageWidget-Setup-1.2.0-win-x64.exe`：双击安装。
- `CodexUsageWidget-Portable-1.2.0-win-x64.zip`：解压后运行 `CodexQuotaWidget.exe`。
- `SHA256SUMS.txt`：安装包和便携包校验值。

程序已包含额度读取组件，无需另装 Node.js、Python 或 Codex CLI。需要这台电脑当前 Windows 用户已有可读取的 Codex 登录信息；未登录时会提示未登录或找不到信息。

安装包不包含制作者的账号、令牌、个人设置或历史用量。本项目是独立社区工具，并非 OpenAI 官方产品。
