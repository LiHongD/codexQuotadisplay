Codex 用量挂件

适用系统：Windows 11，64 位（x64）。
双击安装包完成安装，然后从桌面或开始菜单启动。
安装包已包含额度读取组件，不需要安装 Node.js、Python、PowerShell 脚本工具或 Codex CLI。

账号与额度
挂件通过随附的官方 Codex 组件检测当前 Windows 用户在本机保存的 Codex 登录状态。
有 ChatGPT 账号登录信息且服务返回套餐额度时，显示该账号的剩余百分比。
没有登录信息时，显示“未登录 Codex / 没有找到本机账号信息”。
API Key 登录、登录失效、网络异常、服务没有返回额度时，会分别提示，不显示虚假的 0%。
退出登录或切换账号后，自动检测或点击“重新检测”即可更新；旧账号额度不会作为新结果保留。
仅在浏览器网页或远程设备中登录，并不保证这台设备有可用的本机 Codex 登录信息。
临时会话或其他 Windows 用户保存的登录状态无法读取。

显示与操作
每 60 秒自动刷新；右键可立即刷新。
默认只有一个双额度能量球：内侧水量表示 5 小时额度，外环表示 7 天额度；球心显示两个百分比。
主界面只显示额度。鼠标停在球面上，会提示两组额度的本地重置日期、时间和剩余时长。
水色固定为清澈浅蓝，不随主题变化；水下红白鲤鱼会摆尾游动，低水位会缩小。选择静态动效可暂停游动。
正常大小 176 像素，可右键调整到 128–280 像素，或按 Ctrl 滚轮、拖动球体右下侧边缘缩放。
左键拖动到屏幕任意边缘会自动吸附，并缩成 68 像素小球，仍显示两个额度。
悬停展开，移开后收起；拖离边缘恢复正常大小。
右键可以设置置顶或不置顶、关闭自动吸附、取消吸附，也可以设置主题和动效。
吸附不会强制置顶；置顶开关独立保存。双击刷新，右键查看详细账号状态或退出。
原有图表仍可从右键选择，已改成只显示额度的紧凑布局。
窗口、外观和动效设置保存在 %LOCALAPPDATA%\CodexUsageWidget\settings.json。

隐私
安装包没有打包制作者的登录凭据或账号信息。
挂件不导出登录令牌，不向制作者或第三方服务器上传账号信息。
随附的官方 Codex 组件会按照本机配置联系 Codex 服务并管理已有登录会话。
挂件只请求账号状态和额度，不发送模型对话或消耗推理额度。

卸载
在 Windows“设置 → 应用”中卸载“Codex 用量挂件”，或从开始菜单运行卸载。
卸载保留挂件的外观设置和原有 Codex 登录状态。
